
Scalable Real-Time Chat Application with Microservices & OTP System | RabbitMQ, Socket.IO

•	Built a production-ready chat application using MERN stack with microservices architecture (User, Mail, Chat services) for better scalability, and implemented OTP-based login using Redis Upstash for OTP storage and rate limiting (1 OTP/min) to prevent spam and ensure secure authentication.

•	Used RabbitMQ for communication between services by sending OTP email events asynchronously, containerized the it using Docker for consistent deployment, and implemented Socket.IO (WebSockets) for real-time features like instant messaging, typing status, online/offline users, and read receipts with fast updates.

•	Added core chat features like image sharing using Cloudinary for file upload and storage, along with chat functionalities like messaging and user interactions, and deployed it completely on AWS EC2 for production making it fully production-ready.
